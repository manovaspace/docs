# Security

This policy covers the documentation site's source and build dependencies.
For a library vulnerability, use the affected package repository's security policy.
No security support window or response SLA is promised here.

## Report routing

Open the repository's [Security page](https://github.com/manovaspace/docs/security).
If **Report a vulnerability** is available, use that private form with affected
commit/version, impact and reproduction steps. GitHub explains the process in
[private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
The feature must be enabled by maintainers; this document does not verify that setting.

If no private form or verified private maintainer contact is available, open a
[routing-only issue](https://github.com/manovaspace/docs/issues/new) asking for a
private reporting channel. Include no exploit, sensitive details or credentials
in that public issue. Share the report only after maintainers provide a private
channel. Maintainers must establish and verify that channel before advertising
private reporting as enabled or declaring public release readiness.
