# Contributing

This repository is the public documentation site for `@manovaspace/*`
([manovaspace.github.io/docs](https://manovaspace.github.io/docs/)).

## Guidelines

1. Keep pages generic — no client-specific product names, private URLs, or credentials.
2. Match existing page structure under `src/content/` (or the current content tree).
3. Prefer Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`.

## Development

```bash
bun install
bun run build
```

Questions: open an [issue](https://github.com/manovaspace/docs/issues).
